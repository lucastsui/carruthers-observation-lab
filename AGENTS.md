# CEDA application entry point

This Git repository is normally inside the owner's Carruthers research workspace.
When present, read `../AGENTS.md` for the project instructions and use
`../CURRENT_STATE.md` as the concise handoff for orientation or continued work.
Maintain that parent handoff after meaningful progress; avoid duplicating it here.

In a standalone clone where these private workspace files are absent, use the
current user request and the relevant sections of `README.md`. Start with its
**Task map** to locate code/tests; consult **Scientific rules to preserve** for
scientific changes and `deploy/nightglow/README.md` for deployment work. Read
sections on demand rather than loading the entire README. Do not copy private
research notes or source observations into this repository.
